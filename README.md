# Astro SSR

Пример приложения [Astro](https://astro.build/) с серверным рендерингом (SSR), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `4321` |
| Путь проверки состояния | `/` |

Railpack ставит зависимости, собирает проект (`npm run build`) и запускает `npm run start`.
Сервер собирается адаптером [`@astrojs/node`](https://docs.astro.build/en/guides/integrations-guide/node/)
в режиме `standalone` и слушает `0.0.0.0` (`server.host: true` в `astro.config.mjs`). Порт
берётся из переменной окружения `PORT` — её передаёт платформа, — а без неё `4321`.

Статическая версия — `app-example-astro`.

## Что показывает пример

- `/` — страница рендерится на сервере при каждом запросе: время рендера, версия Node.js и `User-Agent` уже подставлены в HTML.
- `/about` — вторая страница приложения.
- `/api/hello` — API-эндпоинт, отдаёт JSON.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск в дев режиме с отслеживанием изменений
npm run dev

# сборка для продакшн
npm run build

# запуск собранного приложения
npm run start
```

Для работы нужен Node.js 22.12 или новее.
