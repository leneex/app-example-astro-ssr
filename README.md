# Astro SSR

Example [Astro](https://astro.build/) app with server-side rendering (SSR). Astro is a web framework for content-focused websites that ships pages as HTML with as little JavaScript as possible.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `4321` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in dev mode with watch
npm run dev

# build for production
npm run build

# run the built app
npm run start
```

Requires Node.js 22.12 or later.
